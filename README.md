# Pedro Hand

Fonte autoral criada a partir da caligrafia de **Pedro Henrique Santos Garcia**.

Gosto da minha letra e tive a ideia de transformá-la em uma fonte funcional. O resultado já aparece no jogo O Tirano e no meu portfólio.

## Experimentar

Baixe o repositório e abra **Teste a fonte.html** no navegador, mantendo a pasta `web` ao lado do arquivo. A demonstração permite digitar, alterar o tamanho e conferir caracteres.

## Arquivos

- `PedroHand.ttf` e `PedroHand.otf`: formatos instaláveis. Escolha um dos dois.
- `web/`: arquivos WOFF/WOFF2 e estilos para a web.
- `caracteres.png`: prancha de caracteres da versão 1.1.

## Processo

Escrita à mão → digitalização → vetorização → organização dos glifos → exportação e aplicação.

Os arquivos desta versão foram preparados e refinados com auxílio do ChatGPT/Codex, preservando o traço pessoal como ponto de partida.
